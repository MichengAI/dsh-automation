## 目标与业务边界

实现 DeepSeek Harness 的独立任务自动化：用户或 Agent 保存一条自包含任务，Host 到期后在全新 Session 中执行，并留下可审计历史。设置页提供任务列表、执行记录和新建模态。

## 验收标准

1. Web 和 Agent 都能创建、列出、暂停、恢复、立即运行和删除。
2. 到期后创建新 Session，消息 source 为 `automation`。
4. 重启不会偷偷重跑遗留 running。
5. 删除定义不删除运行历史。
